Backup e ajuda

O sistema salva automaticamente cadastros e pedidos no banco de dados local deste computador. Para ter um arquivo de backup em Downloads, toque em Exportar backup. Não limpe os dados do Chrome sem antes exportar uma cópia.

Atenção: esta versão não usa Supabase. Clientes, produtos e pedidos ficam armazenados localmente no computador; não há sincronização entre aparelhos. Exporte backups regularmente. Como não há login, qualquer pessoa que abrir o arquivo neste aparelho poderá acessar os dados.

Como usar

  1. Cadastre seus clientes na aba Cadastro de Clientes.
  2. Cadastre os itens e preços na aba Produtos.
  3. Monte um pedido na aba Solicitar Pedidos e clique em Salvar pedido.
  4. Use Imprimir no pedido para imprimir ou salvar como PDF.
  5. Use Exportar backup para guardar uma cópia dos seus dados.

Esta versão é uma aplicação local simples. Ela não emite nota fiscal eletrônica, não transmite pedidos pela internet e não substitui um sistema fiscal/contábil.
